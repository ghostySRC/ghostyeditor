GhostyLinux
Cloud v2

Real Linux.
In your Chromebook.

The new GhostyLinux runs on a real 64-bit Linux cloud machine instead of emulating an ancient 32-bit PC in your tab. You get a graphical desktop, Firefox, Chromium, terminal, Git, Python, Node, compilers and normal Linux package installs.

Launch full 64-bit GhostyLinux Run local emulator
First cloud launch has to build the desktop image. After that, Codespaces can resume it. Port 6080 is configured to open the Linux desktop automatically.

x86_64

ghostylinux@cloud:~$ git clone https://github.com/OWNER/PROJECT.git

ghostylinux@cloud:~$ sudo apt install package-name

Private desktop portThe desktop is forwarded through your authenticated GitHub Codespace instead of exposing VNC directly.

What changed from v1?

v1 remains available as Local Mode and runs entirely inside Chrome using WebAssembly. Cloud v2 trades that offline/local design for a much more capable machine: x86-64, far more RAM, multiple cores, modern browsers, normal package installation, and a persistent Codespace filesystem. It automatically stops when idle so it doesn't keep using compute while you're away.
